# 機能改善の提案

現状のコード（ホールド・ゴースト・7-bag・ハイスコア・効果音・消去アニメ・ポーズ実装済み）を踏まえた改善案。効果が大きい順に記載。

## 操作性の改善（体感への影響が大きい）

1. **逆回転（反時計回り）の追加**
   現在は ↑ の時計回りのみ。`Z` キーで反時計回りを追加すると、壁際での置き方の自由度が大きく上がる。標準的なテトリスでは CW/CCW 両方が基本。
   変更は `Tetromino.cs` に `RotatedCcw()`、`GameEngine.cs:159` の `Rotate()` の共通化、キーバインド追加程度で小さめ。

2. **ロックディレイ（接地猶予）**
   現在は接地した瞬間に即固定される（`GameEngine.cs:133-136`）。接地後 約0.5 秒の猶予を設け、その間は移動・回転で置き直せるようにすると、高レベルでの操作感が劇的に良くなる。ガイドライン準拠なら「移動/回転でリセット、最大 15 回まで」。

3. **DAS/ARR（横移動の自作キーリピート）**
   現在の横移動は WPF の `KeyBinding` 頼みで、OS のキーリピート設定に依存する。押しっぱなし時の初動遅延（DAS）とリピート間隔（ARR）を自前のタイマーで制御すると、端まで一気に寄せる操作が安定する。

## ゲーム性の拡張

4. **NEXT の複数表示（3〜5 個）**
   現在 NEXT は 1 個のみ。エンジンは既に 7-bag のキューを持っているので、`IReadOnlyList<TetrominoType> NextQueue` を公開して先読み数を増やすのは比較的簡単で、戦略性が上がる。

5. **コンボ（REN）と Back-to-Back ボーナス**
   連続ライン消去や連続テトリスへの加点。スコアシステムに深みが出る。既存の加点処理（`GameEngine.cs:292-295`）への追加で済み、テストも書きやすい機能。

6. **T-Spin 判定と加点**
   上級者向けの定番機能。ただし判定にはウォールキック情報が必要で、現在の簡易キック（`GameEngine.cs:166-176`）を SRS（スーパーローテーションシステム）準拠に置き換えるのとセットになるため、工数は大きめ。

## UI / その他

7. **ウィンドウサイズ変更対応**
   現在は固定サイズ（`ResizeMode="CanMinimize"`）。盤面一式を `Viewbox` で包むだけで、高 DPI や小さい画面でも快適になる。実装コストが最小の割に効果がある。

8. **音量設定・ミュート切替**
   効果音実装済みなので、`M` キーでのミュートやスライダーがあると親切。

9. **統計表示**
   プレイ時間、ピース数、テトリス率などをゲームオーバー時に表示。

## おすすめの着手順

まず「1. 逆回転」か「4. NEXT 複数表示」が小さく効果的。操作感を本格的に良くするなら「2. ロックディレイ」が本命だが、タイマー制御と既存の固定処理の絡みでテストケースが多くなる。
